# Data Cleaning Project using Python & Pandas

A beginner-friendly data cleaning project built in Jupyter Notebook using Pandas. It turns a raw dataset into a clean, analysis-ready one.

## Steps Performed
1. **Deleting redundant columns**: removed columns not useful for analysis
2. **Dropping duplicates**: removed repeated records
3. **Cleaning individual columns**: fixed data types, formatting and inconsistent values
4. **Handling NaN values**: removed or filled missing data
5. **Further transformations**: checked for any additional cleaning needed

## Tech Stack
- Python
- Pandas
- Jupyter Notebook

## How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas jupyter`
3. Open the notebook: `jupyter notebook`
